# Security Policy

## Supported Versions

This repository is maintained on a best-effort basis. Security fixes are prioritized for the current default branch.

## Reporting a Vulnerability

Please do not report a vulnerability through a public issue when it could expose users before a fix is available.

Use GitHub's **Private vulnerability reporting** for this repository when enabled. Include:

- A clear description of the issue and affected files or versions
- Reproduction steps or a minimal proof of concept
- Expected impact and any suggested mitigation
- Screenshots or logs that can be shared safely

You can also contact the repository owner through their GitHub profile. Sensitive secrets must never be included in reports.
